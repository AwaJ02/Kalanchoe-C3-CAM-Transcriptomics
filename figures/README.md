# Figures

This directory contains the final figures generated from the transcriptomic
analysis of *Kalanchoë fedtschenkoi* and used in the MSc dissertation.

Figures include:

- Principal component analysis (PCA) of RNA-seq samples
- Differentially expressed gene counts across the diel cycle
- Directional KEGG pathway enrichment
- KEGG metabolic pathway visualisations
- Expression patterns of CAM-associated genes
- Candidate gene visualisations

Figures were generated from the processed RNA-seq and functional annotation
results using R and KEGG pathway mapping.

For differential expression analyses, positive log2 fold-change values
represent higher expression in mature LP6 (CAM) leaves, while negative values
represent higher expression in young LP1 (predominantly C3) leaves.

Note that colour conventions used in KEGG Mapper visualisations are specified
in the relevant figure legends.
