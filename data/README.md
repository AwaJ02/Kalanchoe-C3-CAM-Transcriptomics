# Data

This directory contains information describing the RNA-seq dataset used in this project.

## Experimental design

The dataset consisted of 36 RNA-seq samples from *Kalanchoë fedtschenkoi*.

Samples represented:

- Two developmental stages:
  - LP1 – young leaves, predominantly C3
  - LP6 – mature leaves, established CAM
- Six diel sampling timepoints: 10, 14, 18, 22, 02 and 06 h
- Three biological replicates for each developmental stage × timepoint combination

## Input data

The analysis used:

- Raw RNA-seq gene count data
- Sample metadata
- *Kalanchoë fedtschenkoi* EggNOG functional annotations
- Gene-to-KEGG Orthology (KO) mappings

The original RNA-seq count and annotation files are not included in this repository unless redistribution permission is available.

Processed results and summary outputs generated during the analysis are provided in the `results` directory.
