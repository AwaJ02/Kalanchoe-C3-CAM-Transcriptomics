# Supplementary CAM Gene Analysis

This directory contains supplementary outputs supporting the analysis and
prioritisation of CAM-associated genes in *Kalanchoë fedtschenkoi*.

The files include:

- CAM-associated genes identified within development × time interaction pathways
- Candidate pathway-driver genes
- CAM-relevant enriched pathways
- Results from the initial search for core CAM-associated genes

These tables provide supporting evidence for the candidate-gene analyses
reported in the main results.

The principal CAM gene summary and final candidate prioritisation table are
provided in the `results/` directory.
