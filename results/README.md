# Results

This directory contains processed outputs generated from the transcriptomic
analysis of *Kalanchoë fedtschenkoi*.

The results include:

- Differential gene expression summaries across six diel timepoints
- Developmental stage × time interaction analysis
- Functional annotation summaries
- Directional KEGG pathway enrichment results
- CAM-associated gene analysis
- Prioritised candidate genes

Differentially expressed genes were defined using an adjusted p-value < 0.05
and |log2 fold change| > 1.

Positive log2 fold-change values indicate higher expression in mature LP6
(CAM) leaves, whereas negative values indicate higher expression in young
LP1 (predominantly C3) leaves.

Only processed analysis outputs relevant to the final dissertation are
included in this directory.
