# KEGG Pathway Enrichment Results

This directory contains directional KEGG pathway enrichment results for
differentially expressed genes across six diel timepoints in
*Kalanchoë fedtschenkoi*.

Enrichment was performed separately for genes with higher expression in:

- LP6 mature CAM leaves
- LP1 young predominantly C3 leaves

Results are provided for 10 h, 14 h, 18 h, 22 h, 02 h and 06 h.

The tables report pathway enrichment statistics including gene ratio,
background ratio, fold enrichment, adjusted p-value and the genes
associated with each enriched pathway.

Only pathways passing the adjusted p-value significance threshold are
included.
